# Guitar Mastering

Личный тренажёр занятий на электрогитаре: разминка, разбор нового, повторение и импровизация.
Работает на Vercel и открывается внутри Telegram как Mini App. Требования описаны в [docs/PRD.md](docs/PRD.md).

## Что уже есть

- **Сегодня:** план занятия из 4 блоков, собранный из библиотеки:
  - разминка — фиксированный набор упражнений;
  - разбор нового — до 2 элементов «В работе», первыми идут те, что дольше всего не играл;
  - повторение — элементы из ротации, закреплённые всегда первыми;
  - импровизация — случайная тональность и прогрессия; задание можно перебросить кубиком.
- **Занятие:**
  - таймер блока; на паузе время стоит; когда время блока вышло — звуковой сигнал и вибрация, блок можно продлить на 5 минут;
  - экран не гаснет;
  - упражнения по очереди: описание, чистый, целевой и последний темп, ссылки, кнопка «На грифе»;
  - метроном сам ставится на темп упражнения;
  - «Записать результат»: темп и оценка (чисто / с ошибками / не вышло); когда цель достигнута, приложение предлагает перевести элемент в ротацию;
  - в конце — итог занятия и новые рекорды;
  - если перезагрузить страницу, занятие не пропадёт.
- **Импровизация:**
  - тональность и прогрессия из 13 вариантов (ii–V–I, минорная ii–V–i, блюз, вампы, rhythm changes…), аккорды с септаккордами;
  - лады на всю прогрессию и под каждый аккорд на грифе, звуки аккорда подсвечены;
  - задание-ограничение, прослушивание прогрессии, поиск бэкинга на YouTube.
- **Метроном:**
  - точный планировщик на Web Audio, 30–300 bpm, tap-темп;
  - 2–7 долей в такте, акцент на первую долю;
  - деление доли: четверти, восьмые, триоли, шестнадцатые, секстоли;
  - speed trainer (+N bpm каждые M тактов до цели), вспышка экрана на долю.
- **Библиотека:**
  - стартовый набор: разминка, техника под Paul Gilbert, теория, Technical Difficulties и Ascend с разделами;
  - статусы «В работе / Очередь / Ротация / Архив»;
  - карточка элемента: темп, разделы песни, график чистого темпа, история, заметки, ссылки.
- **Прогресс:** недели и занятия без пропусков, минуты за неделю и месяц, прогресс целевых песен по разделам, календарь, время по блокам, рекорды.
- **Теория:**
  - интерактивный гриф: 14 ладов, позиции (боксы пентатоники и «3 ноты на струну»), аккорды лада;
  - аккорды и аппликатуры shell / drop 2 / drop 3;
  - полноэкранный гриф для пюпитра.
- **Настройки:** длительности блоков, дни занятий, параметры грифа, бэкап в файл и загрузка из файла.

Данные пока хранятся на устройстве (localStorage). Синхронизация и Telegram-бот — следующий этап.

## Стек

Vite + React + TypeScript, Tailwind CSS, Zustand, React Router.
Музыкальная теория — свой модуль `src/music` (ноты пишутся по ступеням: в фа мажоре B♭, а не A♯), покрыт тестами.
Звук — Web Audio API.

## Разработка

```
npm install
npm run dev        # http://localhost:5173
npm test           # тесты теории
npm run build      # проверка типов + сборка в dist/
```

## Деплой на Vercel

1. [vercel.com](https://vercel.com) → **Add New… → Project** → импортируй репозиторий.
2. Framework Preset определится сам (**Vite**), настройки в `vercel.json`. Нажми **Deploy**.

Telegram-бот, напоминания и синхронизация будут подключены так же, как в `my-english-vocab` (см. PRD, раздел 8.2).
