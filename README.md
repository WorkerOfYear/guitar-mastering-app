# Guitar Mastering

Личный тренажёр занятий на электрогитаре: разминка, разбор нового, повторение и импровизация.
Работает на Vercel и открывается внутри Telegram как Mini App. Требования описаны в [docs/PRD.md](docs/PRD.md).

## Что уже есть

- **Теория** — интерактивный гриф:
  - 14 ладов и звукорядов: пентатоники, блюзовая, лады мажора, гармонический и мелодический минор, фригийский доминантовый, альтерированный;
  - позиции: 5 боксов пентатоники (у блюзовой — с блюзовой нотой внутри), 7 позиций «три ноты на струну» для ладов;
  - подписи: ступени, ноты, интервалы от аккорда, пальцы; при нажатии на ноту звучит звук и подсвечиваются все такие же ноты;
  - аккорды лада (Imaj7, ii7…): нажми, и звуки аккорда подсветятся поверх лада; терция и септима выделены отдельно;
  - аккорды: 14 типов, арпеджио по позициям, аппликатуры shell / drop 2 / drop 3; при нажатии на диаграмму аккорд звучит;
  - полноэкранный гриф для пюпитра: в ландшафте помещается весь гриф.
- Каркас остальных экранов: «Сегодня», «Библиотека», «Прогресс», «Настройки» (настройки грифа уже работают).

## Стек

Vite + React + TypeScript, Tailwind CSS, Zustand, React Router.
Музыкальная теория — свой модуль `src/music` (ноты пишутся по ступеням: в фа мажоре B♭, а не A♯), покрыт тестами.
Звук — Web Audio API.

## Разработка

```
npm install
npm run dev        # http://localhost:5173
npm test           # тесты теории
npm run build      # проверка типов + сборка в dist/
```

## Деплой на Vercel

1. [vercel.com](https://vercel.com) → **Add New… → Project** → импортируй репозиторий.
2. Framework Preset определится сам (**Vite**), настройки в `vercel.json`. Нажми **Deploy**.

Telegram-бот, напоминания и синхронизация будут подключены так же, как в `my-english-vocab` (см. PRD, раздел 8.2).
