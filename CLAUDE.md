# Правила для Claude в этом репозитории

## Публикация изменений

- После каждой законченной и проверенной правки **сразу заливай её в `main`** — спрашивать не нужно, это постоянное разрешение владельца.
  Vercel деплоит сайт из `main`.
- Порядок: коммит в рабочую ветку → `git push` рабочей ветки → `git fetch origin main` → если `main` является предком текущего коммита,
  `git push origin HEAD:main` (fast-forward). Если `main` ушёл вперёд — сначала влей его в рабочую ветку (`git merge origin/main`),
  прогони проверки и только потом пушь.
- Перед заливкой должны проходить: `npx tsc --noEmit`, `npm test`, `npm run build`. Сломанное в `main` не лей.
- Никогда не делай force-push в `main`.
